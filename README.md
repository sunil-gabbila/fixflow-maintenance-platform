# FixFlow – Smart Maintenance and Complaint Management Platform

FixFlow is a cloud-native, microservices-based Smart Maintenance and Complaint Management Platform built with Java 21, Spring Boot, Spring Cloud, Apache Kafka, MySQL, and React.
